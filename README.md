# go-api-gin

# 🐹 Go API – Produtos

Um projeto de exemplo em **Go**, demonstrando a criação de APIs RESTful com **Gin**, boas práticas de desenvolvimento e integração com PostgreSQL via Docker.

---

## 💻 Tecnologias utilizadas

- [Go](https://golang.org/) – linguagem principal
- [Gin](https://github.com/gin-gonic/gin) – framework web
- [PostgreSQL](https://www.postgresql.org/) – banco de dados
- [Docker & docker-compose](https://www.docker.com/) – ambiente isolado
- [godotenv](https://github.com/joho/godotenv) – variáveis de ambiente

---

## 🚀 Funcionalidades

- CRUD básico de produtos
- Respostas em **JSON** padronizadas
- Separação em camadas:
  - `controller`
  - `usecase`
  - `model`
- Tratamento de erros adequado
- Configuração de variáveis sensíveis com `.env`
- Ambiente replicável com Docker
