Tecnologias Utilizadas

Backend:

Go – linguagem principal

Gin – framework web para construção da API REST

PostgreSQL – banco de dados relacional

godotenv – gerenciamento de variáveis de ambiente



Frontend:

HTML – estrutura da interface

CSS – estilização

JavaScript – consumo da API via requisições HTTP



Infraestrutura:

Docker & Docker Compose – ambiente isolado e replicável



Funcionalidades:

CRUD completo de produtos

Interface web integrada consumindo a API

Respostas JSON padronizadas

Separação em camadas

Configuração de variáveis sensíveis via .env
